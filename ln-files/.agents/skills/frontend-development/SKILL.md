Choose the narrowest applicable reference. For user-journey or visual-product decisions without an implementation request, use `product-design` instead.

- UX, accessibility, and interface-guideline review: `references/web-design-guidelines/guide.md`
- React composition API design: `references/vercel-composition-patterns/guide.md`
- React or Next.js performance work: `references/vercel-react-best-practices/guide.md`
- React Native or Expo implementation and performance: `references/vercel-react-native-skills/guide.md`
