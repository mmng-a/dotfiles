# Google Drive Finder

Google DriveはFinder同期済みのローカルファイルとして扱う。APIやブラウザを使わず、次の同期ルートを起点に操作する。

```text
/Users/masashiaso/Library/CloudStorage/GoogleDrive-aso@sendocorp.jp/
```

## 操作手順

1. 依頼にパスが含まれない場合は、上記ルート配下を対象にする。
2. 検索はまずファイル名・フォルダ名で行い、必要な場合だけ内容を読む。候補が複数あるときは、パスと更新日時を示す。
3. 作成、更新、移動では、対象の完全パスと変更内容を確認してから実行する。同期中のファイルを扱うため、完了後に存在・サイズ・更新日時を確認する。
4. 削除、既存ファイルの上書き、名前変更、フォルダ一括移動は、対象を列挙してユーザーの明示承認を得てから実行する。

## 注意事項

- Finderの表示だけを根拠にせず、ファイルシステム上の実体を確認する。
- Google Driveの共有設定、権限、コメント、版履歴はローカル同期フォルダから変更しない。必要な場合は、ユーザーにGoogle Drive上での操作を依頼する。
- Google Docs、Sheets、Slidesの内容はローカル上で直接編集できないことがある。対応するローカルファイルがない場合は、その制約を報告する。
- ファイル名・パスに空白や日本語が含まれるため、完全パスを安全に引用して操作する。
