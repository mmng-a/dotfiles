# Workspace Context

Use only when the request depends on desktop state rather than files, a purpose-built connector, or terminal output.

- Recent screen history or ambiguous reference to work just performed: `references/chronicle/guide.md`
- Explicit full-screen, window, or pixel-region screenshot request: `references/screenshot/guide.md`

Prefer a purpose-built connector or local inspection when it can answer the question without accessing the desktop.
