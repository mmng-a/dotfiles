# Ponytail Help

この環境の `ponytail` は、過剰な実装を抑えるローカル版。現在必要な機能・安全性・読みやすさを保ち、追加する機能・抽象化・設定・依存関係の必要性を確認する。

Codexでは `$ponytail` で指定できる。過剰な実装が懸念される作業では自動選択の対象となり、適用は現在の作業に限る。強度の段階や環境変数による常時有効化は使わない。

| スキル | 用途 |
|---|---|
| `ponytail` | 実装・設計中に、不要な追加を抑える |
| `ponytail-review` | 差分から過剰な実装を探す |
| `ponytail-audit` | リポジトリ全体の簡素化候補を報告する |
| `ponytail-debt` | 既存の `ponytail:` コメントを集める |
| `ponytail-gain` | 原典の測定値を表示する。このローカル版の効果を示す測定ではない |

関連スキルの実行・変更範囲は、それぞれの指示と依頼内容で確認する。レビューや削除を一括で起動しない。

このローカル版は原典と動作が異なる。更新時は差分と利用方針を確認し、原典のファイルでそのまま上書きしない。
