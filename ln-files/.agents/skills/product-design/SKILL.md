# Product Design

Read the one reference that matches the product surface. Use `frontend-development` when the request is primarily web or React implementation rather than product-design judgment.

- Consumer apps, onboarding, commerce, community, or content browsing: `references/consumer-app-design/SKILL.md`
- SaaS, admin tools, dashboards, or workflow-heavy interfaces: `references/product-interface-design/SKILL.md`
- Native iOS patterns or SwiftUI: `references/mobile-ios-design/SKILL.md`
- VoiceOver, Dynamic Type, keyboard access, or other iOS accessibility work: `references/ios-accessibility/SKILL.md`
- Figma URL, node ID, variables, screenshots, or assets: `references/figma/SKILL.md`
- Faithful Figma-to-code implementation: `references/figma-implement-design/SKILL.md`

Start from the target users and the primary task. Preserve source design context and accessibility requirements through implementation.
